# Privacy Checklist

## V0

- [ ] No login.
- [ ] No persistent favorites.
- [ ] No behavioral personalization.
- [ ] No personal data storage.
- [ ] No service role key in frontend.

## V1

- [ ] Explicit consent for account/preferences.
- [ ] Preference data is clearly explained.
- [ ] User can edit preferences.
- [ ] User can delete account/data.
- [ ] Data retention is documented.

## V2

- [ ] Behavioral tracking has explicit consent.
- [ ] User can opt out.
- [ ] User can delete behavioral history.
- [ ] Personalization is explainable.
- [ ] Logging avoids sensitive data.
