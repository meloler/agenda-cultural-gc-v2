# Playbook: Implement Feature

1. Read `PROJECT.md`, `PRODUCT_SPEC.md`, `ARCHITECTURE.md`, `feature_list.json` and `progress.md`.
2. Confirm the feature ID and scope.
3. Create or update a plan in `docs/plans/active/`.
4. Identify files likely to change.
5. Confirm no secret or production operation is needed.
6. Implement the smallest useful slice.
7. Run relevant validation from `TESTING.md`.
8. Update `progress.md`.
9. Do not mark `passes:true` unless acceptance criteria and validation are satisfied.
