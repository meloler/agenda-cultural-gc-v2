# Playbook: Add API Endpoint

Status: future-facing. There is no API layer in V0 yet.

1. Confirm an API endpoint is actually needed.
2. Document the contract first.
3. Do not expose service role keys to frontend clients.
4. Add validation and error states.
5. Add tests before relying on it.
6. Update `SECURITY.md` if permissions or data access change.
7. Update `progress.md`.
