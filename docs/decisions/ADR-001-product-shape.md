# ADR-001: Product Shape

## Status

Accepted for V0.

## Context

Agenda Cultural GC should not behave like a chronological agenda. The core user need is deciding what to do in Gran Canaria, usually on mobile and with limited time.

## Decision

The product will be a mobile-first discovery guide organized around dynamic collections and intent.

V0 collections:

- Top planes de hoy.
- Este finde.
- Gratis o baratos.
- Con niños.
- Música en directo.
- Teatro y escena.
- Mercadillos y ferias.
- Joyas escondidas.

## Consequences

- The home is not a calendar-first page.
- Filters are secondary to discovery.
- Event cards must help decide quickly.
- Ranking must be explainable.
- Data quality matters more than raw volume.
