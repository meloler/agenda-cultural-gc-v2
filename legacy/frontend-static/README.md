# Legacy Static Frontend

This folder contains the previous static frontend for Agenda Cultural GC.

## What It Contains

- The former root `index.html`.
- The former vanilla `app.js` SPA.
- The former `style.css` stylesheet.
- PWA files such as `manifest.json` and `sw.js`.
- Static prototype pages and Stitch design artifacts.
- Frontend-only helper assets such as `purify.min.js`.

## Why It Is Preserved

This code is historical product knowledge. It shows previous navigation, event cards, map/calendar/list views, Supabase usage, visual experiments and mobile prototypes.

It must not be deleted during the controlled rebuild.

## What It Is Not

This is not the base of the new app.

The new product direction is a mobile-first discovery guide organized as dynamic collections, closer to Netflix/Spotify than to a chronological agenda.

## How To Use It

Use this folder only as reference when rebuilding:

- UI patterns worth preserving.
- Data access examples.
- Edge cases already handled.
- Copy, empty states or event detail ideas.

Do not add new product features here unless explicitly working on legacy maintenance.
